1. Introduction

Welcome to ShellTerm! This is a free terminal that represents Linux so you don't have to download Linux on your computer and do all the complicated stuff. Now, with ShellTerm, you can use all the available Linux commands and uses live tracking like viewing file information, listing all your files, etc.

2. How To Use ShellTerm

The program is used as a simple straightforward terminal that acts exactly like linux but with one of ShellTerm's additions. Here's a summary of how to use ShellTerm's commands.

 * Help: Used for listing all commands without additional information.
 * Files: Lists every single file on your computer.
 * Wait: Waits for the inputted seconds.
 * Echo: Sends a message added after the echo command.
 * Pwd: Shows the current OS you are using.
 * Mkdir: Creates a folder on your computer.

...and more. Type 'help' in the terminal for an list of even more commands.

3. What is ShellTerm?

ShellTerm is used as a simple terminal made using Python and acts exactly as Linux. Bug reports are being found in the code sometimes. If a bug is found, we will fix it immediately. ShellTerm also uses every command that Linux provides.
